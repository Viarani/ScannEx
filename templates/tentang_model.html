Tentang Model — untuk juri

Keluar

Bukti kerja ilmiah — model, data, dan evaluasi terbuka termasuk keterbatasan.

Dataset

Dua data berbeda. (a) Klasifikasi — 11 kelas: 10 kelas e-waste (battery, keyboard, microwave, mobile, mouse, pcb, player, printer, television, washing_machine) + 1 kelas non_electronic. Distribusi sangat timpang: non_electronic ~20.500 gambar, tiap kelas e-waste hanya ~200–300 gambar (lihat grafik distribusi di model/__results___files). Augmentasi flip/rotate/brightness. (b) Clustering — 3.637 foto e-waste valid untuk 16 komunitas makro (silhouette 0,774). Lisensi: CC BY 4.0 (cantumkan sumber asli setelah verifikasi).

Arsitektur

Klasifikator 11 kelas — backbone vit_base_patch16_siglip_gap_224.v2_webli (ViT-B/16, patch 16, 224×224) + head klasifikasi. 10 kelas e-waste + 1 kelas non_electronic. Ekspor ONNX: model_quantized.onnx 87 MB (float32 345 MB), input 3×224×224, normalisasi mean/std 0.5.

11 kelas | 87 MB | inferensi CPU ±200 ms/foto

Pelatihan

Fine-tune EMA di atas backbone pra-latih SigLIP2/WebLI, checkpoint terbaik disimpan sebagai best_finetuned_ema.pt. Augmentasi ringan untuk foto HP. Tantangan utama: distribusi kelas timpang — non_electronic ~20.500 gambar vs ~200–300 gambar untuk tiap kelas e-waste, sehingga model cenderung ragu pada kelas minoritas.

Evaluasi

Confusion matrix 11 kelas + galeri prediksi salah tersimpan di model/__results___files. Contoh kesalahan yang teramati: mobile → television (layar HP mirip TV), microwave → battery pada foto label perangkat, dan non_electronic → microwave pada foto oven/kompor. Karena ketidakseimbangan kelas, model sengaja dibuat konservatif: keyakinan rendah ditolak lewat ambang confidence, bukan dipaksa menebak.

Uji foto dunia nyata

50-100 foto sendiri (latar berantakan, cahaya redup, barang rusak) vs test set bawaan — laporkan selisih akurasi sebagai bukti generalisasi.

Kalibrasi confidence

Ambang “tidak yakin” ditentukan dari eksperimen, bukan asal.

Eksperimen: 122 tile foto e-waste (dipotong acak dari montase 64 komunitas) sebagai set elektronik, dan 16 foto acak non-elektronik sebagai set penolakan. Setiap gambar dijalankan ke model ONNX (softmax top-1) lalu di-sweep threshold 0,10–0,70.
Sweep threshold (ACC = akurasi seimbang rata-rata dari dua kolom):
Threshold E-waste diterima (semua / yang benar dikenali) Foto non-elektronik ditolak ACC
0,1560,7% / 97,4%9/1658,5
0,1856,6% / 90,8%12/1665,8
0,20 (dipakai)50,0% / 80,3%13/1665,6
0,2535,2% / 56,6%14/1661,4
0,3031,1% / 50,0%15/1662,4
0,4517,2% / 27,6%15/1655,5
Catatan: 46 dari 122 tile e-waste justru diprediksi non_electronic (banyak tile berlatar putih / kolase) — tile itu selalu ditolak berapapun threshold-nya, sebab itu kolom “semua” mentok di 62,3%. Nilai ambang dipilih di titik ACC tertinggi yang tetap masuk akal: 0,20.

Aturan penolakan di aplikasi (clf_gate di app.py):
1. Prediksi = non_electronic dengan confidence ≥ 0,20 → tampil “Ini sepertinya bukan barang elektronik”.
2. Confidence < 0,20 → tampil “coba lagi!” + saran foto ulang.
3. Lolos keduanya → label model ditampilkan, kelompok visual (kNN) tetap ditampilkan sebagai bukti pendukung.
